# FE-Social-Media

👉 **Live Demo:** [Connected Social Media Platform](https://connected-social-media.online)

Frontend application for Social Media platform built with React, featuring real-time communication, NLP-powered content evaluation, and comprehensive user interaction features.

## Getting Started

### Prerequisites

- Node.js (v20)
- PNPM package manager

### Installation and start project

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm dev
```
